## 💡 Detailed Program Descriptions

### 1. Prime Number Checker (`prime.java`)
Checks whether a given number $N$ is prime or composite for $T$ test cases using optimized trial division up to $\sqrt{N}$.

- **Time Complexity:** $\mathcal{O}(\sqrt{N})$ per test case
- **Space Complexity:** $\mathcal{O}(1)$

---

### 2. Pattern Printing

#### Pattern 1 (`pattern1.java`)
Prints an increasing right-angled triangle star pattern:
```text
*
**
***
****
*****
```

#### Pattern 2 (`pattern2.java`)
Prints a decreasing inverted right-angled triangle star pattern:
```text
*****
****
***
**
*
```
